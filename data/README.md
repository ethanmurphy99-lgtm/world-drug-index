# Data (withheld pending publication)

The raw country-level indicator workbook (`database_input.xlsx`) used by
`WDI_validation.R` is **not included in this repository**. It is being held
back until the associated World Drug Index paper is published, at which
point the dataset will be released with a citable DOI (following the same
approach used for the [European Drug Index dataset on Zenodo]()) and this
folder, or the script's `INPUT_DIR` pointer, will be updated accordingly.

`weights.xlsx` (the indicator weighting scheme) is already included at the
repository root, since it's required for the script to run and isn't
itself country-level survey data.
